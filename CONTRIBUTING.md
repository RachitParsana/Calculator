# Contributing Guidelines

Thank you for your interest in contributing to the Calculator project.

These guidelines describe the basic workflow contributors should follow when making changes to the repository.

## Before Contributing

Before making a contribution:

1. Read the `README.md` file.
2. Understand the existing project structure.
3. Check existing issues before reporting a new problem.
4. Keep changes focused on the intended purpose.
5. Verify changes before creating a pull request.
6. Do not commit passwords, API keys, access tokens, or other sensitive information.
